# 🏦 Secure Bank Account Simulation

A Java-based Banking Simulation System designed to demonstrate Object-Oriented Programming principles while modeling real-world banking operations such as deposits, withdrawals, balance tracking, and transaction history management.

---

## 🛡️ Project Overview

This project simulates a secure banking environment where users can perform basic account operations through a command-line interface.

The system implements:

* Account Management
* Transaction Processing
* Balance Verification
* Transaction Auditing
* OOP Design Principles

---

## 🚀 Features

### 💰 Deposit Funds

Securely add funds to the account.

### 💸 Withdraw Funds

Withdraw money while enforcing account constraints.

### 📊 Balance Monitoring

View current account balance in real-time.

### 📜 Transaction History

Maintain an audit trail of all account activities.

### 🔐 Minimum Balance Protection

Prevents withdrawals that violate minimum balance requirements.

---

## 🧠 OOP Concepts Demonstrated

| Concept           | Implementation                 |
| ----------------- | ------------------------------ |
| Encapsulation     | Private/Protected Fields       |
| Inheritance       | SavingsAccount extends Account |
| Method Overriding | Customized Withdraw Method     |
| Polymorphism      | Runtime Method Resolution      |
| Constructors      | Account Initialization         |
